.. index:: pair: bravo; charlie

Pair Entry
----------

A ``pair: a; b`` entry: generates both "bravo > charlie" and its reciprocal
"charlie > bravo".

.. index:: triple: delta; echo; foxtrot

Triple Entry
------------

A ``triple: a; b; c`` entry: generates three rotations, "delta > echo
foxtrot", "echo > foxtrot, delta" (note the comma), and "foxtrot > delta
echo".
